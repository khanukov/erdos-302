# Mixed prefix data export (not a proof)

`python independent_bank/mixed_prefix_export.py > mixed-prefix.json` emits canonical compact UTF-8 JSON with a final newline. The CLI reads the compressed bank via `archive_prefix.load_bank`, checking its pinned SHA-256 before parsing with duplicate-key rejection; its `source_sha256` identifies those compressed source bytes, not the JSON output or parsed object. It exports exactly nodes 0 through 1090 inclusive; unsupported node types, changed taxonomy counts, short input, malformed supported data, non-backward references, invalid image scales or invalid interpreter checks fail instead of dropping data. Redirect to a new temporary file and rename only on success if overwriting a valuable file. The Python API `export(bank)`/`render(bank)` accepts an already-parsed bank and **does not authenticate it** or emit source provenance, even when passed a bank loaded from the archive. Neither a hash label nor this export authenticates a subsequently modified output; verify output bytes independently.

The finite node array has 1,091 entries, indexed exactly 0–1090, without a default/dummy node: 1,080 `basic`, seven `case_placeholder` (4, 7, 14, 35, 67, 72, 78), three `trim_placeholder` (5, 8, 15), and one `pack` (1090, from archive `qpack`). There are 371 reference occurrences: 361 case, three trim, seven pack; collapsing repeated source-node pairs gives 189 directed edges. Every edge points from an entry to a strictly smaller node ID, so this finite graph is acyclic. No later nodes or archive roots are exported.

Each entry retains interpreted normalized `support` and `demand`. Basic and placeholder records preserve their exact archive object; placeholders also include resolved, occurrence-ordered image references. Pack rows retain exact rational numerator/denominator, image index, source, multiplier and divisor; `normalizer` is the gcd of their unnormalized image union. The result contains enough literal data for a future constructor adapter to decide how to represent case trees, trim, scaling, and packing. A placeholder is explicitly **not** a checked mixed-DAG constructor and must not be interpreted as a proof or a fake leaf. Consumers must fail closed until those constructors and all their obligations are available and kernel checked.

The Python `interpret` and exhaustive small checks are useful validation, but are not Lean proof, a verified parser or a proof that archive semantics agree with the target Lean checker. In particular, any future adapter must separately prove/check normalization and rational packing translation and provide genuine case/trim proofs. Candidate Lean constructors are not assumed to compile here.

Run `python -m unittest discover -s independent_bank -p test_mixed_prefix_export.py`. The tests compare every archived payload/reference occurrence, reject malformed mutations, ensure a valid substituted node cannot gain in-memory provenance, and compare CLI bytes across hash seeds. For the pinned bank, CLI output has 167416 bytes and SHA-256 `709fb086774a5f90b90d1089b128c751f59c986f4242cc9cb416dd22443b813`.
