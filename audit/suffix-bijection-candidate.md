# Suffix split and occurrence count: candidate, not kernel-checked

The candidate takes disjoint finite sets `P` (earlier primes) and `S` (suffix primes). Its proposed inverse uses `SmoothPartition.decomposition_exists S m`: extract the whole S-smooth factor, leave a positive S-rough factor, then inherit P-roughness from `m`. Uniqueness uses `decomposition_unique`. Conversely, if q is (P ∪ S)-rough and t is positive S-smooth, disjointness makes q*t P-rough. These two Lean proof scripts and the interface tests are **uncompiled**; existence itself is an earlier uncompiled candidate. Disjointness is unused in the split direction, but is essential to the reverse direction.

`multiplicity S N a b q` counts every positive suffix-smooth `t ≤ N/q` with `a ≤ N/(q*t) < b`. `indices` is the positive final-rough set through N. The proposition `CellCountIdentity` spells out the desired equality against the actual `ArchiveSummation.cellCount` predicate, without taking that equality as an assumption. It is a proposition definition, **not a theorem**. For the archive instantiate P and S with the earlier and suffix prime sets, with every element prime and `Disjoint P S`; require 0<a and 0<b. The quotient lemma already handles reversed/empty cells. N=0 has no indices and no occurrences.

To complete the proof, construct a `Finset.card_bij` between the cell-filtered m and the dependent pair finite set of q and t. For forward m, use `suffixSplit S m` and the split existence/uniqueness result; for reverse pairs use q*t and `product_prefix_rough`.
