# Node 1209 exact ancestry and scoped bridge candidate

The script `independent_bank/node1209_scope.py` reads the same SHA-256-pinned compressed bank as `archive_prefix.load_bank`. It traces references from node 1209, preserving occurrences, remaps the induced DAG, and replays it with `bank_interpreter.interpret` and `verify_bank.small_only`. No external leaf is invoked. This is a Python check, not kernel evidence or a proof that the publication archive is authentic.

* 376 distinct nodes, 1056 reference occurrences (not unique edges): 368 small, 4 case, 3 trim, 1 pack.
* Non-small node IDs: case 4, 7, 14, 1190; trim 5, 8, 15; pack 1209. No qpack or externalActive node occurs in this ancestry. In particular the four external leaves at 1097, 1107, 1112 and 1114 are **not** needed for this source's induced DAG, even though the whole-bank sequential replay assumes them.
* 139 ancestors lie in 0..255, 209 in 256..1023, and 28 in 1024..1209. The last group is 26 small leaves, case 1190 and pack 1209. The 256 and 1024 claims refer to actual generated mixed-prefix literals: prior prefix-256 success is at its own historical SHA; the prefix-1024 aggregate is a candidate, not verified merely because its representative shard passed. Both would need same-environment identity bridges, and the prefix-1024 data defaults beyond 1023.
* Node 1209 is a 510-row weighted pack, capacity 1001, normalizer 1, and Python replay produces 901 support vertices and demand 258. The independently emitted node support matches the existing extension source literal in a Python comparison. Reference counts are occurrences, not distinct predecessor nodes.

`lean/Node1209SourceCandidate.lean` contains the concrete 510-row node, a proposed kernel-checked support identity, and a conditional exact 258 bridge using `MixedCaseTrimCandidate.sound`. `python independent_bank/node1209_scope.py --check` independently regenerates the candidate byte-for-byte. Neither this candidate nor its axiom reports have been compiled. Its prefix hypothesis is deliberately stronger than the 376-node closure: a literal actual prefix through 1209 contains the four externalActive nodes, which the non-external payload cannot represent or check as actual nodes. Thus the candidate does not remove the source hypothesis and is not itself a workable replay of the complete actual prefix. A future closure-aware induction must preserve actual original indices, prove all 376 checks from checked predecessors, and supply actual rules and exact identities for all ancestors; alternatively explicitly handle the external rules in a full-prefix theorem. Kernel-check the large support equality and pack (capacity, weight and target-demand) certificates in bounded shards, verify case 1190 and all intervening small nodes, then assemble with axiom gates. The generated root and extension literals' equality is distinct from proving provenance from archive bytes. No 258 or 242 unconditional bound is claimed.
