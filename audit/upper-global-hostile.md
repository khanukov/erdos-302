## Reasoning examined adversarially

1. **Projection.** If exactly one of a,b,c is divisible by p, the equation bc=a(b+c) is impossible modulo p (including the case where that vertex is a). If two or more of an edge are odd, the equation fails modulo 2; hence every edge has at most one odd vertex. For arbitrary prime set Q, every edge not wholly in the Q-smooth part T has at least two vertices outside T: select a prime outside Q dividing an outside vertex. At least one of those outside vertices is even. Consequently adding all *even* vertices of S\\T to a cover of H(T) covers H(S), giving the claimed subtraction. This remains valid when 2 is or is not in Q, when Q is empty, and when the projected demand is negative. An explicitly checked boundary hitting set U need not be minimum and gives the same extension argument. Removing T vertices above n costs at most their number, not necessarily exactly that number. These arguments require H(T) to be the induced reciprocal hypergraph and the source assertion to hold for the actual support S; both are essential.

2. **Full prefix versus active support.** Removing genuinely isolated vertices preserves cover number, so a *full* smooth-prefix lower bound may be transferred to its complete edge-active support. Conversely that inference is unjustified if the active support omits any vertex of any edge, or if the external profile denotes a different graph/demand. verify.py:125–128 constructs the full P20-smooth prefix, enumerates its edges, and keeps all endpoints; mathematically that step is valid provided the old profile really bounds that same full prefix. The fact that a profile has the right final aggregate is insufficient to validate each intermediate level or the interpretation of an external theorem. I have not established the upstream correspondence.

3. **Renewal.** For distinct primes p_j, the two pieces S_(j-1)(n) and p_j S_j(floor(n/p_j)) are disjoint and exactly partition S_j(n). A cover of the whole graph restricts to covers of both induced subgraphs; cross-edges can only increase the required cover size. This proves the recurrence lower bound, not an equality for the true cover number. Monotonicity of true prefix cover numbers validates the `U_j(n-1)` seed below cutoff. With j increasing and n increasing, n//p_j<n and all dependencies have already been defined. The max includes the renewal term, so d_j(n)>=0 even if a previously positive correction is absorbed by a stronger parent. Extending using d=0 for n>X preserves the lower-bound property by induction; no unproved analytic tail estimate is required. The extension need not be assumed monotone: only its lower-bound property and recurrence are used in the global sum.

4. **Reindexing and endpoint.** Multiplication by a positive integer q is an injective reciprocal-edge-preserving dilation, so disjoint smooth/rough blocks furnish simultaneous cover constraints. Expand U_j(t)=d_j(t)+U_(j-1)(t)+U_j(floor(t/p_j)) repeatedly; termination holds because each p-division reduces t and U_j(0)=0. Unique p-adic valuation converts the inner q,p^a sum to rough integers for P_(j-1); floor(floor(N/q)/p^a)=floor(N/(qp^a)). All sums are finite for fixed N. For a cell [a,b), floor(N/q) in that cell is **exactly** N/b<q<=N/a, including integer endpoints; no rounding or endpoint is lost. A=b is an empty cell; actual reported cells have strict a<b.

5. **Error and quantifiers.** Inclusion-exclusion for m=j-1 excluded primes uses 2^m divisors. The difference of each pair of floor errors for the half-open interval has absolute value <1, hence the crude bound 2^m (and the archive's looser 2^j) is valid, including j=1, q=1 and N<a. Summing h times the absolute errors gives E=sum_j 2^j sum_cells h, uniformly for every integer N>=1. There is no omitted correction tail beyond X because d_j was explicitly set to zero there; an entire U_j tail still exists and is accounted for recursively. Divide the finite inequality by N and let N tend to infinity to obtain a limsup bound, without assuming a density limit. The printed headline is an upper rounding, not the exact C.
