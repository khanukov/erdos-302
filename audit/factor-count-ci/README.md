# Factor-count CI inventory (unverified candidate)

The workflow `.github/workflows/factor-count-candidate.yml` builds the complete local import closure in the order checked by `closure.py`, against Lean v4.33.0-rc1 (release SHA-256 pinned) and teorth/mathlib4 commit `da1f94df976c7cd38117281c57d6ee3046c8d104`. The project manifest in `audit/mathlib-bridge-ci/project` pins mathlib's own dependencies. The checkout action is pinned to a commit and credentials are not persisted. The Ubuntu runner image is version-selected, not immutable.

Local production closure: Renewal, SmoothRenewal, Summation, BlockAccounting, SmoothPartition, SmoothExistence, SmoothCover, RoughCoprime, CellEquivalence, SuffixBijectionCandidate, FactorCountCandidate. Tests and axiom-report modules import the candidate. Direct mathlib imports are listed by `closure.py`. If imports drift, the inventory check fails rather than silently omitting a dependency. Compilation starts with no local oleans.

The independent axiom report checks decomposition existence and uniqueness, rough/coprime equivalence, quotient-cell equivalence, the suffix split, product roughness, and the candidate theorem. The four named concrete test theorems have their own gates. The checker permits only `propext`, `Classical.choice`, and `Quot.sound`, rejecting missing reports and `sorryAx`/`ofReduceBool`. Transitive theorem dependencies are included by Lean's axiom reporting. These are proposed checks, not evidence of a successful run.

The concrete Lean examples target a nonzero cell (N=6, a=1, b=2, count 3), zero N, and reversed endpoints. Omitted-assumption tests check that elaboration cannot prove each missing premise from the remaining assumptions; they are not by themselves countermodels. Independent Python finite models provide explicit counterexamples for overlap, composite prefix and each zero endpoint. The candidate and examples have not been compiled locally; CI must run before any kernel-verification claim. In particular, these checks do not prove archive prime-index correspondence or the renewal/cover estimate.
