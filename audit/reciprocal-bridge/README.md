# Candidate same-environment reciprocal bridge CI

Overlay this directory's `.github` and `audit` onto the main repository containing `audit/upper-small-bridge/UpperBridge.lean` and `audit/mathlib-bridge-ci/project/`. This is a candidate, not a reported passing Lean build.

The upstream snapshot `9447ceb28138949b2fb32442cec506a6f53104f9` uses Lean 4.27.0 and Mathlib `a3a10db0e9d66acbebf76c5e6a135066525ac900`. UpperBridge uses Lean 4.33.0-rc1 and Mathlib `da1f94df976c7cd38117281c57d6ee3046c8d104`. The two `.olean` formats/environments are not assumed interchangeable. The recursively discovered local source-import closure of `Erdos302CoverRowsFC` at the upstream snapshot consists of exactly `Erdos302CertificateCoreFC` then `Erdos302CoverRowsFC`; both are copied byte-for-byte and compiled from source under the latter environment. Source hashes and upstream commit are checked. Mathlib and dependencies use the UpperBridge pinned manifest; the script checks their materialized git revisions. The cached Mathlib objects are not rebuilt from source if the official cache is available. Upstream objects and UpperBridge/ReciprocalBridge objects are always freshly built in a new directory.

Feasibility: the local upstream closure is small (two files, 382 and 231 lines), so a source rebuild is a practical CI experiment, not evidence it compiles on the newer API. Migration breakage in either whole upstream file can block import even if the definition itself is unchanged. CI must establish success; no local Lean was available. The Lean archive digest, exact UpperBridge source digest, lower source digest, and project manifest digest are pinned to the existing bridge workflow. Lack of Mathlib cache may exceed the job time limit. Hosted CI has not been run and no compatibility or proof success is claimed.

The test checks actual `Erdos302CoverRowsFC.NoUnitFractionCover`, positive triples and both denominator orders, repeated denominator and zero regressions. Axiom reports for selected load-bearing declarations are checked against `propext`, `Classical.choice`, `Quot.sound`; this is not an audit of every declaration in the upstream files. The predicate bridge does not establish archive translation or a global theorem.
