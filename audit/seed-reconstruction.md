# Conditional independent seed and max-recurrence replay

Run `python3 independent_bank/seed_reconstruction.py` and `python3 -m unittest discover -s independent_bank -p 'test_seed_reconstruction.py'`. The input is the repository ZIP, checked against SHA-256 `9396819eb36e25926d7ae8ee78b85c61cb898801f935fccfe72ebcad491bc196`. The same in-memory bytes are hashed and parsed; only named data members are read, archive code is never executed. The hash pins bytes, not author provenance.

The pre-existing independent interpreter checks 4,106 normalized bank witnesses, conditionally assuming four old-profile external bounds. For each of 515 extensions this implementation enumerates all reciprocal edges directly within its source support and checks each edge outside the target meets the deleted vertices. This exhaustive within-support enumeration is different from the archive's smooth-universe divisor enumeration but tests precisely the edges needed for each extension. It checks reported outside-edge counts and uses projected witnesses alongside all bank results. The `old` extension field is syntactically checked but is not used to derive a witness or compared with the old profile.

For each of 20 levels it constructs a seed array from these witnesses, computes old and new profiles through n=500000 using the source max recurrence, derives corrections as `new[n] - parent[n] - new[n//p]`, groups maximal positive runs, and checks exact cells, u32le table SHA-256, level metadata and global rational arithmetic against the report. A full run matched all 20 levels and 4,705 cells; finite error is 55064831540 and exact upper is 5257732070693282578339807052385333596114146444258874863366093099862086223334703221767412397/6250046986665851271465761945238620015244311869639997944823697072137494392402703576166400000.

This is executable corroboration, not a kernel proof. It assumes soundness of the existing Python interpreter, the four external old-profile bounds, projection and renewal mathematics, and arithmetic implementation. It does not prove the source bytes correspond to Lean literals, certify every bank rule or extension in Lean, establish the tail beyond 500000, or discharge the global cover/endpoint premises. The 20 arrays are transient in-memory values; their comparison to report hashes is not independent of the trust in the pinned report data. No Lean build was run.
