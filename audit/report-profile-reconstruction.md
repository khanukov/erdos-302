# Data-only reconstruction of the 20 reported profiles

`tools/reconstruct_report_profiles.py` verifies the tracked publication ZIP SHA256 `9396819eb36e25926d7ae8ee78b85c61cb898801f935fccfe72ebcad491bc196` before reading exactly two named members in memory, and verifies the bytes of the archive baseline `VERIFIED_REPORT.json` (SHA256 `abefb2c518a98cbb80a000fac3441133006db89e58fb1ef4ffacf12b6a2a1c48`) and `upstream_intervals.json` (SHA256 `b9f1b518c895fffc8efe40b6abb9b39cd877ef77ef0c78b5211b5b103b117111`). Hashing and parsing use the same in-memory bytes. The hashes match the baseline's SHA256SUMS, and the upstream interval file names commit `9447ceb28138949b2fb32442cec506a6f53104f9`; hashes alone do not establish provenance. No archive Python was executed.

Run from this worktree:

```
python3 -B tools/reconstruct_report_profiles.py input/erdos302_boundary_certificates_publication.zip
```

Optional `--output DIRECTORY` writes twenty 500001-entry little-endian 32-bit unsigned arrays (including index zero); these are generated data, not Lean proof objects. At each prime in `(3,2,5,...,71)`, start with U_j(0)=0 and U_0(n)=0, and compute `U_j(n) = U_(j-1)(n) + U_j(n // p_j) + sum(h for [a,b,h] in cells_j if a <= n < b)`. This is a compact finite recurrence certificate for the report's *claimed* tables, with the cells as inputs, not an independent derivation of those cells.

Execution checked all 20 advertised SHA256 hashes of u32le tables, all 4,705 ordered non-overlapping positive half-open cells and their per-level heights, J and rho, nonnegativity, monotonicity, and pointwise domination of independently reconstructed old interval profiles at every n through 500000. It recovered error 55064831540 and the exact report coefficient. Every cell-derived value of d matches the reconstructed table difference by construction; cells end no later than 500001. It does not establish the tail or identify these Python values with Lean literals. Nor does comparing hashes supplied in the same report prove the tables were generated by the bank or satisfy a cover bound.

## Source-to-profile derivation still needed

`baseline/verify.py:84–168` describes how the 4106 bank nodes produce normalized `(S,k)` witnesses, including image transformations, pack/qpack unions, trim and four old-profile external nodes. Its checks must be independently formalized: reading witness labels alone does not prove demands. `:180–216` adds 515 projected extension witnesses, conditional on complete edge enumeration and deletion checks. `:263–267` supplies **all** bank results plus extensions to `renew`; an empty named root map is not an empty witness set.

For each witness `(S,k)` and prime level j, rank vertices by largest prime index, with rank 100 for those not smooth in all 20 primes. Let `allowed` be vertices with rank ≤ j, and `cost` count even vertices of larger rank. Initialize `d = k - cost - len(allowed)`, then traverse allowed in ascending order, increment d and maximize `seed[v]` at each allowed v. For other positions seed is zero. Rebuild old profile L from the reversed upstream interval levels by `L_j(n)=L_(j-1)(n)+L_j(n//p_j)+number_of_old_intervals_containing_n`. Then compute in ascending n

`U_j(n) = max(L_j(n), seed_j(n), U_j(n-1), U_(j-1)(n)+U_j(n//p_j))`.

The missing verification is that the bank/extension-derived seed and this max recurrence produce the report tables and that every operand is a valid smooth-block demand. A proof need not establish equality of the report's seed values if it instead supplies verified lower-bound witnesses sufficient to justify every positive reported correction; proving sufficiency remains work. The present script does not compute the bank results, extensions or seeds, and does not verify this max equation. The archive contains sufficient described inputs for a reconstruction attempt, but availability of a compact independently checked seed certificate has not been established. All-n zero-correction continuation, source-byte-to-Lean translation, and kernel proofs of the local cell identity and graph demand remain open.

The independent synthetic test compares emitted tables to a direct interval-sum recurrence and tests invalid data, including missing cells, duplicate keys and archive members, numerical booleans and mutations. The GitHub workflow runs those tests (also under `-O`) and the complete reconstruction without Lean. Local full reconstruction measured 4.65 seconds and 37,056 KiB peak RSS on this host; CI performance varies. An interrupted or failing run with `--output` can leave partial output; only use output after a successful exit. The hashes are pinned byte identities, not independently authenticated provenance.
